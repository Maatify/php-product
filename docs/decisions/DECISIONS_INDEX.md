# Decision Index

## Discovery Status

This index is the current discovery surface for durable engineering decisions in this repository. Every decision listed below is recorded and indexed with status `ACTIVE`; none is superseded. Owner decisions: `DEC-001` to `DEC-006` resolve the six Product V1 Owner decision gates, `DEC-007` records the Owner approval of the architecture and the start of implementation, and `DEC-008` to `DEC-013` record the Owner decisions of 2026-10-14 that amend the approved architecture. Lead decisions `DEC-014` to `DEC-028` record, within the authority of `DEC-007`, the technical decisions that the Package Reference states and the implementation relies on.
